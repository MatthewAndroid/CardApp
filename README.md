# 🃏 CardApp 

**CardApp** is a lightweight and engaging quiz application built with **Jetpack Compose**. Designed to be simple, intuitive, and fun, it allows users to test their knowledge with true/false questions, get immediate feedback, and track their score.

---

## ✨ Features

* **🚀 Welcome Screen** – Friendly intro screen with a "Start Quiz" button.
* **❓ Question Screen** – Displays one question at a time with true/false options and gives you the user real-time feedback.
* **🏆 Score Screen** – Shows final score and offers options to review answers or restart the quiz.
* **📝 Review Screen** – Recap your responses and compare them to the correct answers.
* **🔁 Quiz Reset** – Automatically resets the quiz when returning to the welcome screen.

## 🛠️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/MatthewAndroid/CardApp
   ```
2. Open the project in **Android Studio**.
3. Connect an Android device or use an emulator.
4. Build and run the app.
